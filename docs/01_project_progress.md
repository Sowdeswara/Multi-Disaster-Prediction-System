# SIH 26178 — Project Progress

## 1. Problem Statement

*“A resilient, AI‑powered environmental monitoring network that provides early detection, localized intelligence, and actionable alerts for floods, forest fires, pollution events, and other environmental hazards common in India, enabling authorities and communities to shift from reactive disaster response to proactive risk prevention.”*

## 2. Project Objective

The aim is to develop a resource‑constrained edge‑AI system capable of ingesting heterogeneous environmental sensor streams across India, transforming them into compact temporal representations, and producing hazard‑specific risk assessments locally on refurbished Snapdragon smartphones.

## 3. Work Completed

- Selection of SIH problem statement 26178.
- Definition of a localized edge‑intelligence architecture.
- Identification and collection of Indian flood‑related datasets.
- Organization of the raw datasets inside the project workspace.
- Preliminary review of dataset structure, variables, and coverage.
- Design of a hierarchical temporal‑memory strategy for low‑resource devices.
- Draft of a multi‑hazard model‑head architecture (flood head as the first target).

## 4. Current Development Stage

> **Current stage:** Flood dataset collection and preliminary dataset review completed. Model development has not yet started.

## 6. Future Expansion

After a validated flood model is in place, the architecture will be extended to incorporate additional hazard‑specific heads (forest fire, landslide, pollution) using appropriate Indian datasets, followed by deployment on edge devices and field validation.
